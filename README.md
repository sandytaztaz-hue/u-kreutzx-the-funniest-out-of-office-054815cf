One line of out-of-office auto-reply, the funniest I can make it, in 140 characters or fewer.

## Entry

> Thank you for applying to reach me. We received 287 emails this week; yours did not make the shortlist. Interviews resume Monday.

129 characters. One line, nothing else.

## Run

`main.py` writes exactly that line to `/output/entry.txt` (no trailing newline) and prints it to stdout. No input, no network, no randomness — the output is byte-identical on every run.

```sh
python3 main.py
```
